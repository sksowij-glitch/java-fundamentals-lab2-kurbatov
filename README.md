## Відповіді на контрольні питання

### 1. В чому полягає різниця між ключовими та зарезервованими словами?
Ключові слова — це слова, які вже використовуються компілятором і мають конкретну дію в програмі (наприклад `class`, `public`, `static`, `if`, `while`, `return`).  
Зарезервовані слова — це ширше поняття, це слова, які зарезервовані на майбутнє або є спеціальними літералами (`const`, `goto`, `true`, `false`, `null`). Їх не можна використовувати як імена для своїх змінних чи методів.

### 2. Які примітивні типи даних Ви знаєте? Для кожного з них наведіть приклади, коли найбільш ефективно використовувати саме цей тип:
У Java є 8 примітивних типів:
1. `byte` (8 біт) — робота з байтами файлів, мережевий потік або збереження масивів кольорів пікселів.
2. `short` (16 біт) — координати точок або 16-бітні аудіо-семпли.
3. `int` (32 біти) — рахунок у футбольному матчі, лічильники циклів, вік людини, індекси масивів.
4. `long` (64 біти) — розмір великого файлу у байтах, кількість зірок у галактиці, час у мілісекундах.
5. `float` (32 біти) — координати 3D-моделей у графіці (де важливіша швидкість, ніж максимальна точність).
6. `double` (64 біти) — фізичні та математичні розрахунки, маса планети або всесвіту, де потрібна висока точність.
7. `char` (16 біт) — один символ (наприклад літера `'A'` або знак гривні `'₴'`).
8. `boolean` (1 біт логічно) — прапорець умови (`true` або `false`).

### 3. Що таке знакові та беззнакові типи? До якої групи відноситься кожен з примітивних типів даних?
Знакові типи можуть зберігати як додатні, так і від'ємні числа (для знака використовується старший біт).  
Беззнакові типи зберігають тільки невід'ємні числа (від нуля і більше).  
- У Java знаковими є цілі типи: `byte`, `short`, `int`, `long`.  
- Єдиним беззнаковим типом є **`char`** (приймає значення від 0 до 65535).  
- `float` і `double` зберігають знак за стандартом IEEE 754.  
- `boolean` не є числовим типом.

### 4. Яке максимальне число можна записати у змінну типу short, char, int, long?
- `short`: $32\,767$ ($2^{15} - 1$)
- `char`: $65\,535$ ($2^{16} - 1$)
- `int`: $2\,147\,483\,647$ ($2^{31} - 1$)
- `long`: $9\,223\,372\,036\,854\,775\,807$ ($2^{63} - 1$)

### 5. Змінна типу byte може приймати значення у діапазоні -128..127. Чому цей діапазон саме такий? Чому від’ємних значень більше ніж додатних?
Тип `byte` займає 8 біт, тобто дає $2^8 = 256$ різних комбінацій.  
Старший біт відповідає за знак (0 — плюс або нуль, 1 — мінус).  
- Для невід'ємних чисел (знаковий біт 0): від 0 до 127 (всього 128 значень).
- Для від'ємних чисел (знаковий біт 1): від -128 до -1 (всього 128 значень).  
Оскільки число 0 потрапило до групи з додатними, то строго додатних чисел вийшло на одне менше (127), ніж від'ємних (128).

### 6. Що таке система числення? Як переводити значення з однієї системи числення у іншу?
Система числення — це набір правил та символів для запису чисел. Вони бувають позиційні (двійкова, десяткова, 16-кова) та непозиційні (римські цифри).  
- Щоб перевести число в десяткову систему: множимо кожну цифру на основу системи у відповідному степені розряду.  
- Щоб перевести з десяткової в іншу: послідовно ділимо число на основу нової системи і записуємо залишки від ділення у зворотному порядку.

### 7. Що таке «Доповняльний код»?
Доповняльний код — це спосіб запису від'ємних чисел у пам'яті комп'ютера.  
Щоб його отримати:
1. Беремо число в двійковому вигляді.
2. Інвертуємо всі біти (замінюємо 0 на 1, а 1 на 0).
3. Додаємо до результату 1.  
Це дозволяє комп'ютеру віднімати числа за допомогою тієї ж схеми додавання.

### 8. Пояснити результат роботи коду:
```java
int a = 2_000_000_000;
int b = 2_000_000_000;
int c = a + b;
System.out.println(c);
```
**Результат:** виведеться від'ємне число `-294967296`.  
**Чому так:** тип `int` обмежений значенням $2\,147\,483\,647$. Справжня сума $4\,000\,000\,000$ перевищує це значення. Відбулося цілочисельне переповнення (overflow), через що число "перескочило" у від'ємну область.

### 9. Чим тип float відрізняється від double?
1. Розмір: `float` займає 4 байти (32 біти), а `double` — 8 байтів (64 біти).
2. Точність: `float` має близько 7 точних цифр після коми, а `double` — близько 15-16.
3. Запис: для числа `float` обов'язково треба писати літеру `f` в кінці (наприклад `3.14f`), а `double` пишеться просто як `3.14`.

### 10. Що таке число з рухомою комою? Що таке мантиса та степінь?
Число з рухомою комою — це форма запису дробових чисел у комп'ютері, де кома не стоїть на одному місці, а зсувається: $M \cdot 2^E$.
- **Мантиса** — це дробова частина, яка показує самі значущі цифри числа (його точність).
- **Степінь (порядок)** — показує, на скільки позицій потрібно зсунути кому (масштаб числа).

### 11. Що таке Double.NaN?
`NaN` розшифровується як "Not a Number" (не число). Це спеціальне значення, яке виникає при некоректних математичних діях, наприклад ділення `0.0 / 0.0` або корінь з від'ємного числа `Math.sqrt(-1)`.

### 12. Пояснити результат коду:
```java
System.out.println(Double.NaN == Double.NaN);
```
**Результат:** виведе `false`.  
**Пояснення:** за стандартом IEEE 754 значення `NaN` не дорівнює нічому, навіть самому собі. Щоб перевірити, чи число є NaN, використовують метод `Double.isNaN(x)`.

### 13. Пояснити різницю між преінкрементом та постінкрементом
- **Преінкремент (`++x`):** спочатку збільшує значення на 1, і у вираз підставляє вже збільшене число.
- **Постінкремент (`x++`):** спочатку повертає старе значення для використання у виразі, а вже потім збільшує змінну на 1.
Приклад:
```java
int a = 5; int res1 = ++a; // res1 = 6, a = 6
int b = 5; int res2 = b++; // res2 = 5, b = 6
```

### 14. В чому різниця між логічною та побітовою операцією AND? Чому коротка версія (&&) тільки логічна?
- Звичайна `&` — побітова (працює з бітами чисел) або повна логічна (завжди обчислює обидві частини, ліву і праву).
- Коротка `&&` — тільки логічна. Якщо ліва частина `false`, то праву частину комп'ютер навіть не рахує, бо результат і так буде `false`.  
Коротка версія є тільки логічною, тому що в числах не можна пропустити обчислення якихось бітів.

### 15. В чому різниця між OR та XOR?
- **OR (`|` або `||`):** дає `true`, якщо хоча б один операнд `true`.
- **XOR (`^`):** дає `true` тільки тоді, коли один `true`, а другий `false` (якщо обидва однакові, то буде `false`).

### 16. Проаналізувати фрагмент програми:
```java
boolean a = true && false | false;
System.out.println(a = false);
boolean b = true && false || false;
System.out.println(b = true);
```
**Результат:**
```text
false
true
```
**Пояснення:**
1. Побітове `|` має вищий пріоритет за `&&`. Тому спочатку рахується `false | false` (це `false`), а потім `true && false` (теж `false`).
2. У `System.out.println(a = false)` стоїть оператор присвоєння `=`, а не порівняння `==`. Він присвоює `false` і повертає `false`, тому виводиться `false`.
3. У виразі з `||` оператор `&&` має вищий пріоритет. Спочатку `true && false` (дає `false`), потім `false || false` (дає `false`).
4. У `System.out.println(b = true)` знову присвоєння `=`, тому виводиться `true`.
